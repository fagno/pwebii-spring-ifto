== Convenções de leitura e edição

* A parte de objetos Java mostra referências, coleções e os lados proprietário e inverso. As setas indicam navegação; os números próximos às entidades indicam multiplicidade.
* Na parte relacional, as setas vão da chave estrangeira (FK) para a chave primária (PK) referenciada. UNIQUE indica unicidade e NOT NULL indica obrigatoriedade da coluna.
* Os desenhos são esquemas didáticos; campos sem relação com o conceito podem ser omitidos. Eles não representam todo o DDL gerado pelo provedor.
* Cada SVG contém título, descrição acessível e metadados de procedência. Não utiliza fontes remotas, scripts ou imagens incorporadas de terceiros.
* Os arquivos são vetoriais e podem ser editados como texto ou em um editor SVG. Ao alterar os exemplos, mantenha nomes de campos, cardinalidades e chaves consistentes com o capítulo.
